3. Minimum reproducible process

Main document uses ctexart, processing Unicode and Chinese through XeLaTeX;biblatex selects Biber as the backend.latexmk is responsible for judging and concatenating multiple rounds of XeLaTeX, Biber and the final converged build.

# 构建
latexmk -xelatex main.tex

# 强制完整重建并在错误处停止
latexmk -g -xelatex -interaction=nonstopmode -halt-on-error main.tex

# 清理中间产物
latexmk -C

Desktop font problem analysis

After installing the Chinese TeX Live component, the desktop terminal or Electron/Chromium application may temporarily experience abnormal Chinese character spacing. The verified verdict is that the LaTeX compilation chain itself is not broken, the problem comes from changes in the system Fontconfig fallback candidates, and long-running graphics applications still hold old caches or old mappings.

  1. Record before and after installation fc-match results and system package changes, preserving a comparable baseline.
  2. XeLaTeX's ctex can use the Fandol font that comes with TeX Live by default, and there is usually no need to additionally change the desktop font for basic Chinese support.
  3. Rebuild the Fontconfig cache after the font changes, and completely exit the application that uses font rendering; restart completely if the cache status is still inconsistent.
  4. explicitly specifies the font in the source file, reducing reliance on the desktop's default fallback chain.
Boundary DescriptionSuch phenomena cannot be arbitrarily attributed to a single font file. Reliable conclusions should be based on font matching results, package change records, and process restart comparisons.

7. Conclusion

This test proves that XeLaTeX, ctex, TikZ/PGFPlots, listings, cleveref, siunitx and Biber can form a compact and repeatable Chinese and English scientific research typesetting baseline. All core capabilities are produced in the expected layout; follow-up work should focus on the Chinese localization of reference names and unit connectives, rather than continuing to expand the test space.
