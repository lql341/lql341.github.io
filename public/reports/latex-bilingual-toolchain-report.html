一、测试目标与边界

测试目录包含主文档、BibLaTeX 数据库、构建说明和字体故障记录。验证目标是确认从源文件到 PDF 的完整路径可用，并通过视觉检查确认关键版面没有缺字、方框、重叠或裁切。

这不是字体质量基准、印刷色彩验证或 PDF/UA 无障碍认证；测试数据也仅用于排版展示，表格中的准确率和耗时不代表真实实验结果。

三、最小可复现流程

主文档使用 ctexart，通过 XeLaTeX 处理 Unicode 与中文；biblatex 选择 Biber 作为后端。latexmk 负责判断并串联多轮 XeLaTeX、Biber 和最终收敛构建。

# 构建
latexmk -xelatex main.tex

# 强制完整重建并在错误处停止
latexmk -g -xelatex -interaction=nonstopmode -halt-on-error main.tex

# 清理中间产物
latexmk -C
验收建议构建成功只代表工具退出码正常。仍应渲染全部页面，逐页检查字体回退、公式边界、浮动体位置、代码溢出和文献链接。

值得修正但不阻塞验收

cleveref 的引用名称仍显示为英文，例如 theorem、equation、figure 和 table。若目标是全中文论文，可显式定义对应名称，或检查语言选项与宏包加载顺序。测试中的摄氏温度范围也显示英文连接词 to，正式中文文档宜统一为中文表达。

五、桌面字体故障的定位经验

安装中文 TeX Live 组件后，桌面终端或 Electron/Chromium 应用可能短暂出现中文字符间距异常。已验证的判断是：LaTeX 编译链本身并未损坏，问题来自系统 Fontconfig 回退候选发生变化，而长期运行的图形应用仍持有旧缓存或旧映射。

  1. 安装前后记录 fc-match 结果和系统包变更，保留可比较基线。
  2. XeLaTeX 的 ctex 默认可使用 TeX Live 自带的 Fandol 字体，通常无须为基本中文支持额外改变桌面字体。
  3. 字体变化后重建 Fontconfig 缓存，并完全退出使用字体渲染的应用；缓存状态仍不一致时再完整重启。
  4. 正式成果在源文件中显式指定字体，减少对桌面默认回退链的依赖。
边界说明不能把这类现象武断归因于单个字体文件。可靠结论应建立在字体匹配结果、包变更记录和进程重启对照上。

六、公开版脱敏说明

本报告仅公开通用的宏包组合、构建命令、验证方法与故障机理。未收录源目录绝对路径、本机用户名、主机标识、用户级配置文件内容、安装日志及其他可关联个人环境的信息；作者字段也改写为工具链验证描述。

七、结论

本次测试证明 XeLaTeX、ctex、TikZ/PGFPlots、listings、cleveref、siunitx 与 Biber 可以组成一条紧凑、可重复的中英文科研排版基线。核心能力全部产出预期版面；后续工作应集中在引用名称和单位连接词的中文本地化，而不是继续扩张测试篇幅。
